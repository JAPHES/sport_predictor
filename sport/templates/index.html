A simple prediction experience for choosing a game.

The project combines a Django web interface with a trained decision tree model. Users submit their details and receive a sport recommendation instantly.

Built for a clear machine learning workflow.

1

Clean input form

Name, age, height, and gender are collected through a focused predictor page.

2

Range validation

The app accepts ages from 13 to 19 and shows an error for values outside the range.

3

Instant recommendation

The saved model returns a recommended sport directly on the page after submission.
